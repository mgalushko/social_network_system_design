# social_network_system_design
social network system for course of system design
## Функциональные требования
### Аутентификация пользователя
### Лента
- Чтениие ленты постов подписок
- Чтение ленты выбранного пользователя ( в т.ч. своей)
- Подписка на пользователя
### Реакции и комменты
- Создание реакции на посте
- Создание комментария на посте
### Ресерч мест
- Поиск популярных мест для путешествий
- Поиск и просмотр просмотр постов с выбранных мест
### Работа с постом
- Создание постов:
  - Загрузка фото
  - Выбор места фото
  - Создание описания к посту
- Редактирование поста
  - Редактирование содержимого поста ( коммент, описание, фото, локация)
  - Удаление поста

## Нефункциональные требования
### Средние ожидаемые пользовательские метрики
- Уникальных пользователей в сутки - 10.000.000
- Пользователи СНГ
- 10 просмотров ленты ( по 30 постов) каждым пользователем в день
- 30 реакций и 5 комментов в день от каждого пользователя
- 1 новая подписка в день для каждого пользователя 
- 20 Просмотров отдельных постов в день каждым пользователем
- 3 Поиска постов по выбранному месту в день каждым пользователем
- Создание 1 поста в неделю

### Требования к плафтормам
- Веб-браузеры версий не старше 3х лет
- Android 10+
- IOS 14+
### Ограничения
- Пользователь может создать до 50 постов в день
- Пользователь может добавить до 10 фото в рамках одного поста

### Требования к производительности
#### Latency SLI
- Загрузка ленты подписок до 1.5 секунд
- Загрузка ленты профиля до 1 секунды
- Открытие поста до 1 секунды
- Создание реакции и коммента до 1 секунды
- Поиск постов по конкретному месту до 1.5 секунды
- Загрузка батча фото до 2 секунд
- Создание поста до 2 секунд
#### Оценка RPS
- Просмотр ленты = 10.000.000 * 10/86.400 = ~ 1200 rps
