# social_network_system_design
social network system for course of system design
## Функциональные требования
### Аутентификация пользователя
### Лента
- Чтениие ленты постов подписок
- Чтение ленты выбранного пользователя ( в т.ч. своей)
- Подписка на пользователя
### Реакции и комменты
- Создание реакции на посте
- Создание комментария на посте
### Ресерч мест
- Поиск популярных мест для путешествий
- Поиск и просмотр просмотр постов с выбранных мест
### Работа с постом
- Создание постов:
  - Загрузка фото
  - Выбор места фото
  - Создание описания к посту
- Редактирование поста
  - Редактирование содержимого поста ( коммент, описание, фото, локация)
  - Удаление поста
